## What this is
A mobile real-time strategy game (formerly Colony Mobile) in a single self-contained HTML file (index.html). It plays in landscape on iPhone with no dependencies and no network once loaded. Since v2.57 the source is in src/ and `npm run build` (build.js, no dependencies) joins it into index.html: edit src/, never index.html directly, then build and commit both (tests/build.test.js checks they match). The code is organized into marked sections: SIM (rules, combat, AI), RENDER (drawing) and UI (HUD, input, menus).

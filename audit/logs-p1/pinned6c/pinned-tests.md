# Tests pinned to rework switches off, and their switches-on counterparts (batch 6c, Part A2)

Scope: every `test(...)` in tests/*.test.js and tests/slow/*.test.js run with at least one `REWORK` switch off (file-level
`sim.REWORK.x = false`, a local one, `rework: { x: false }`, or a harness `code:` string). Counterparts are in
`tests/switches-on-6c.test.js` (123 tests, about 50 s, run 4 times, 0 failures). "Re-run" means the original test body is
run again from its own file on a SIM whose switches are held on (writes to `REWORK` ignored); every re-run listed below
passed. "Switch test" means the test checks the switch itself, on and off, in the same test (covered by itself).
"Switch-off behaviour" means the test checks a unit or rule that the switch replaces; its counterpart is the rework file's
test of the new rule.
